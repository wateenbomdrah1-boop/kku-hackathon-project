# Discover Your Future

## What it does

Discover Your Future is a bilingual (English and Arabic) quiz that helps students explore the Vision 2030 sectors that match their interests. It asks ten scored scenario-based questions, then offers an optional creative leadership-colour bonus, and shows an instant interest-distribution result.

## Who it is for

Students who want a playful starting point for exploring future study and career fields.

## Needs

A modern web browser. The page is standalone and does not need an internet connection, a server, or an account.

## How to run it

1. Open `index.html` by double-clicking it.
2. Enter a full name and a whole-number age from 1 to 120.
3. Select **Start Quiz** to begin.
4. Use the language button at the top to switch between English and Arabic.

The welcome details stay only in the current browser session. Selecting **Take quiz again** clears them and returns to the welcome form.

## Try it with the sample data

The quiz uses fictional built-in question and sector data. It does not save participant entries or send them anywhere, so no separate sample-data loader is needed.
